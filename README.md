## The entry

`main.ts` writes exactly one letter to `/output/entry.txt`: **A** — coffee.

One letter, no word, no explanation, no punctuation. Coffee is the vivid
pick: bold, dark, loud, alive in the cup — the single letter that lands as
the fuller, more awake answer in the coffee-against-tea argument.

## Run it

```sh
node main.ts   # Node 22.18+ (grader runs Node 22.23.4)
```

Deterministic: no input is read, no time or randomness is used, every run
writes the same single byte.
